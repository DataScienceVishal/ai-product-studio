## Observations, not changed (accepted risk, for the owner)

- Chat path keeps its documented rule that any text is an answer, so a `content_filter` or `length` reply with partial text is saved as the summary (Low; Responses path rejects these).
- `disabled` is a per-process, in-memory flag: it resets on restart and each replica trips separately (by design: "fix config and restart"). Calls already in flight when it flips finish and are kept and billed.
- `_check_reported_model` is check-then-set without a lock: two simultaneous dearer replies can log the error twice. Harmless (bool write is atomic in CPython).
- The reply that trips the guard is still returned to its user (already billed).
- `finish_reason` is provider text and is logged unsanitised in "ai returned no usable answer" (Low: a hostile provider only).
