### Amendment 4, 2026-11-24 (before any model run, including tuning)

Studio Lead decisions D1 to D4, made before any model call. Pass marks, the 30 test sheets, the 5 tuning sheets, their seeds and truth are unchanged (the committed data is byte-identical; the reproducibility test passes).

1. **D1 Blends.** A material cell naming a blend of PET and rPET with shares (for example "rPET 30% + PET 70%") has truth = the canonical material with the largest stated share; a tie goes to "PET". Scorer: `quote_ok` for key `material` accepts a quote naming several canonical materials only if every named material carries a percentage in the quote and the value is the unique largest (tie goes to PET; a tie that excludes PET has no winner and is rejected). "rPET + PET" without shares is rejected. Mixed-family blends are not generated. Recycled content on one material ("rPET (PCR 100%)", "minimum of 25% PCR kraft paper") is not a blend.
2. **D2 Unit in the label.** `quote_ok` for `weight_g`: if no number+unit parses, a quote containing a label unit in parentheses "(g)", "(gm)", "(gms)", "(grams)", "(kg)" or "(oz)" followed (after `norm_quote`) by a bare number is accepted; the number is converted with that unit. "Weight 25.5" (no unit) is rejected. The extractor prompt gains a line: when the unit is only in the row label, the quote is "label cell | value cell" for that one row. This does not conflict with the rule against joining both columns of a two-column row, which is about side-by-side products; the prompt says so.
3. **D3 Areal and case weights.** A component that gives only gsm, micrometres, gauge or a case, pallet or board weight has `weight_g` truth `missing`. The existing scorer already counts any predicted present value on a truth-missing slot as fabricated (rule: missing -> value is a fabrication); a test shows it. No scorer redesign.
4. **D4 Supplement.** `benchmark/supplement.py`, seed 20261126, 12 sheets S801 to S812 under `benchmark/supplement/` (`data/sheets`, `data/truth`, `manifest.json`), truth in the same schema (optional field `target_item`, new layout value `supplement`, new template values `catalogue`, `two_block`, `unit_header`). Reported separately with the same pass marks (no messy-10 mark, no conflicts in it). It does not decide the kill test; its result goes into the idea file next to the test result.
