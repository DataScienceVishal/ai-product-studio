## Lessons
- Review and forum mining finds repeated pain, but the repeated complaints are almost always about price (Sage), reliability (Xero) or a missing feature that a point tool already sells within months (Dext, FreeAgent, CRMs' material-information forms). Where the complaint is a specific job, the nearest vendor had shipped it by the time the scout searched.
- Xero's idea forum is a good "unshipped" test but a poor "unserved" test: the supplier-statement request is still open while Dext has sold the feature since 2024. Always search the add-on makers (Dext, A2X, Synder, FreeAgent) before writing.
- The only repeated, large and unfixed complaint was Sage 50's renewal prices, and that leads to a data-migration job, which is deterministic. No AI product sits there.
- Forum pages (AccountingWEB, Xero idea forum, FreeAgent support) return 403 to fetches here, so verbatim quotes with dates need a different source or a human check. This limits the review-mining thesis itself.
- Recommendation: stop review-mining for UK SMB accounting add-ons. Fifty-two scored ideas plus this null round point to the same conclusion: document-to-ledger jobs are closed. If the studio keeps scouting, the open space is likely a priced judgement job with a real data partner, which needs Vishal's contact route (selling is locked).
